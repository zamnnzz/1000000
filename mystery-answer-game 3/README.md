# الجواب المجهول

نسخة أولية قابلة للتشغيل للعبة متعددة اللاعبين.

## التشغيل محليًا
1. ثبّت Node.js 18 أو أحدث.
2. داخل مجلد المشروع شغّل:
   npm install
3. ثم:
   npm start
4. افتح من كمبيوتر المضيف: http://localhost:3000

## اللعب من الجوالات على نفس الواي فاي
افتح عنوان IP للجهاز المضيف بدل localhost، مثال:
http://192.168.1.20:3000
ثم أنشئ الغرفة وشارك الرابط أو QR.

## للنشر على الإنترنت
ارفع المشروع على خدمة تدعم Node.js وWebSocket مثل Render / Railway / Fly.io / VPS.

## القواعد الحالية
- الحد الأدنى 4 لاعبين.
- كل لاعب يكتب إجابة وهمية.
- إذا كتب الإجابة الصحيحة، يخفيها النظام من الخيارات ويحصل اللاعب على +1 ولا يصوّت.
- اختيار الإجابة الصحيحة = +1.
- كل لاعب يقع في إجابتك الوهمية = +1 لك.
- لا يستطيع اللاعب اختيار إجابته الخاصة.
