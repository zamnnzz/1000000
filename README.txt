تلفزيون خربان - نسخة جاهزة للرفع

طريقة الرفع:
1) فك الضغط.
2) ارفع محتويات المجلد كما هي إلى Vercel أو أي استضافة Static.
3) الصفحة الرئيسية هي index.html.

الصفحات:
- index.html   الرئيسية
- room.html    الغرفة
- game.html    اللعب
- results.html النتائج

مهم:
هذه النسخة تعمل فوراً بدون قاعدة بيانات أو مفاتيح.
الغرف فيها محلية داخل المتصفح، ومناسبة للتجربة والتصميم.
للعب الحقيقي بين أجهزة مختلفة نحتاج ربط Backend مثل Supabase/Firebase.
