TOP 10 — Session Pairing

النظام الجديد:
1. شاشة العرض هي التي تبدأ كل شيء.
2. تكتب أسماء الفريقين.
3. تحدد عدد الجولات.
4. تختار الفئات بالتناوب بين الفريقين.
5. بعد اكتمال الاختيارات يظهر باركود + رابط الهوست.
6. الهوست يفتح الرابط فقط بعد أن يكون كل شيء جاهز.
7. الهوست يرى الاختيارات ويضغط "ابدأ اللعب".
8. بعدها الهوست يفتح الإجابات ويضغط خطأ وينقل للجولات التالية.
9. شاشة العرض تتزامن فورياً عبر Firebase.

المسار في Firebase:
top10/sessions/{SESSION_ID}

إذا ظهر Permission denied:
استخدم firebase-rules.example.json كمرجع لقواعد Realtime Database.

Vercel:
- ارفع المجلد كاملاً.
- Framework Preset: Other
- لا تحتاج Build Command.
