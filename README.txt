نسخة Zamn Lite
- بدون React
- بدون Babel
- بدون Firebase في هذه المرحلة
- نفس فكرة وهوية الموقع وبطاقات الألعاب
- صفحات الألعاب تعمل عبر /game/slug

ارفع محتويات هذا المجلد مباشرة إلى Vercel كمشروع Static.
لا يوجد npm install ولا Build Command.
بعد التأكد من الشكل والسرعة نضيف تسجيل الدخول والمكتبة وFirebase تدريجيًا.
