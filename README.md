# اكشفها — نموذج Firebase

يستخدم المشروع Firebase Realtime Database المقدم من صاحب المتجر. جميع بيانات النموذج داخل `revealPrototype/rooms` فقط.

المعاينة الحالية محلية. بعد رفع مجلد اللعبة إلى عنوان HTTPS عام ستستخدم روابط اللاعبين والمقدم والباركود ذلك العنوان تلقائيا.

هذه نسخة تجريبية وليست جاهزة للبيع: الإجابات والرسومات موجودة في ملفات العميل وصلاحيات الأدوار في الواجهة فقط. قبل الإطلاق يلزم نقل التحقق من الإجابات وحساب النقاط إلى خلفية موثوقة وإضافة تسجيل جلسات وصلاحيات Firebase مقيدة للمضيف والمقدم واللاعبين. لا تنشر القاعدة بقواعد قراءة وكتابة عامة. لم يعدل هذا النموذج إعدادات أو قواعد المشروع القائمة.

وضع المقدم: يتحكم بالكشف ويصحح إجابات الفرق من شاشة مستقلة.
وضع بدون مقدم: صاحب الجلسة يكشف المربعات واللاعب الأسرع يرسل الإجابة من شاشة جواله.

التدفق: إعداد الفرق والوضع ← غرفة انتظار بالباركود وقائمة المشاركين ← بدء اللعب. الباركود لا يظهر داخل الجولة. دخول المقدم في الانتظار لا يعرض الحل قبل البداية.

القياسات: شاشة العرض تستخدم ارتفاع المساحة المتاحة، وحجم لوحة الصورة يحسب من أصغر حد بين العرض والارتفاع عبر ResizeObserver. اختبرت على 1280×720 و390×600 و320×480 دون تجاوز حدود الصفحة.

شاشة المقدم: السؤال التالي يفتح نافذة اختيار الفريق أو عدم وجود إجابة. تسجل النقاط لكل سؤال مرة واحدة مع إمكانية تصحيح المستفيد عند العودة، ثم ينتقل للسؤال التالي. السابق يحفظ كشف المربعات ولا يضيف نقاطا. نقاط الفريقين أعلى شاشة العرض يمين ويسار.
