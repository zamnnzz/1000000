# من أنا؟ — النسخة 5

تعديل الهوست بدون حذف الميزات السابقة:
- الإجابة ظاهرة للمقدم دائمًا.
- أزرار إظهار/إخفاء الإجابة على شاشة اللعبة موجودة.
- الجولات وتحكم الجرس موجودة.
- لا يوجد توزيع نقاط يدوي +1/+2/-1.
- تحت السؤال يظهر الفريقان بنفس ألوان شاشة اللعبة.
- يختار المقدم الفريق الذي أجاب ثم يضغط "إعطاء النقاط والانتقال للسؤال التالي".
- النظام يضيف نقاط السؤال تلقائيًا.
- إذا كان x2 مفعّلًا للفريق تتضاعف نقاط السؤال تلقائيًا.
- بعد إعطاء النقاط ينتقل تلقائيًا للسؤال التالي.
- السؤال المحسوب يبقى محفوظًا في history ويظهر عند الرجوع له من جابه وكم نقطة حصل عليها.
- إذا كان الفائز بالجرس معروفًا، يُحفظ اسمه أيضًا مع الفريق.
