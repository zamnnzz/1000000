# من أنا؟ — النسخة 3

التغييرات:
- إزالة إعداد أسماء الفرق من واجهة المقدم.
- إزالة تفعيل x2 من واجهة المقدم.
- الإجابة تظهر للمقدم دائمًا.
- زر "إظهار الإجابة على شاشة اللعبة" يرسل حالة reveal إلى Firebase وتظهر الإجابة مباشرة على شاشة اللعبة.
- زر "إخفاء الإجابة" يخفيها مرة أخرى.
- x2 انتقل إلى شاشة الجرس، ولكل فريق استخدام واحد فقط طوال اللعبة.
- عند تفعيل x2 من الجرس، أول نقاط إيجابية يحتسبها المقدم لذلك الفريق تتضاعف ثم ينتهي التفعيل.
- مزامنة تحكم المقدم مع شاشة اللعبة أصبحت مباشرة عبر Firebase.
