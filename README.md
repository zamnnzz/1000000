# من أنا؟ — النسخة 11

مبنية على من انا 10.

التعديلات فقط:
- النجوم الثلاث أعلى شاشة اللعبة أصبحت مؤشر تقدم.
- بعد إنهاء الفقرة الأولى يتلون النجم الأيمن.
- بعد إنهاء الفقرة الثانية يتلون النجم الأوسط.
- بعد إنهاء الفقرة الثالثة تتلون النجوم الثلاث.
- عند دخول كل فقرة تظهر شاشة باسم الفقرة لمدة 3 ثوانٍ ثم تختفي تلقائيًا.
- شاشة الفقرة بنفس ألوان وهوية الموقع مع أنميشن.
- إضافة أنميشن خفيف لظهور عناصر شاشة اللعبة.
