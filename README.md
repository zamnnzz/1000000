# من أنا؟ — النسخة مع شاشة البداية

الصفحات:
- `/` أو `index.html` — شاشة البداية: أسماء الفرق + إعدادات مؤقت الجرس.
- `/game.html` — شاشة اللعبة الرئيسية.
- `/host.html` — شاشة المقدم.
- `/buzzer.html` — جرس المتسابقين.

بعد الضغط على "ابدأ الجولة!" يتم حفظ أسماء الفرق والإعدادات في Firebase ثم الانتقال تلقائيًا إلى شاشة اللعبة.
