# خربانة 📺

MVP للعبة جماعية عربية من نوع: **نص → رسم → تخمين → رسم...**

## الموجود الآن
- إنشاء غرفة بكود 5 خانات.
- دخول 3–12 لاعبًا.
- صاحب غرفة يبدأ الجولة.
- كل لاعب يكتب جملة أولًا.
- توزيع دائري يمنع اللاعب من استلام سلسلته في المرحلة التالية.
- لوحة رسم تعمل بالماوس واللمس.
- انتقال تلقائي عند انتهاء جميع اللاعبين من المرحلة.
- نتائج تعرض كل سلسلة من البداية للنهاية.
- Realtime عبر Supabase.
- تصميم RTL ومتجاوب للجوال.

## التشغيل
1. أنشئ مشروعًا جديدًا في Supabase.
2. افتح SQL Editor وشغّل الملف `supabase/schema.sql` كاملًا.
3. من صفحة Connect في Supabase انسخ Project URL وPublishable Key.
4. انسخ `.env.local.example` إلى `.env.local` وضع القيم الصحيحة.
5. شغّل:

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## النشر على Vercel
- ارفع المشروع إلى GitHub.
- Import Project في Vercel.
- أضف متغيري البيئة:
  - `NEXT_PUBLIC_SUPABASE_URL`
  - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- Deploy.

## ملاحظة مهمة قبل الإنتاج
هذا MVP. الرسومات تحفظ حاليًا كـ WebP Data URL داخل Postgres لتسريع التطوير. قبل إطلاق اللعبة للعامة يفضّل نقل الرسومات إلى Supabase Storage وإضافة تنظيف تلقائي للغرف القديمة وحدود أقوى للمحتوى.
