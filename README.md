# من أنا؟ — النسخة 2

تحسين اتصال المقدم:
- المقدم يرسل Heartbeat كل ثانيتين إلى Firebase.
- شاشة البداية لا تعتمد فقط على `connected=true`.
- تعتبر المقدم متصلًا إذا كان `lastSeen` حديثًا.
- يوجد فحص مباشر احتياطي كل ثانية في حال تأخر listener.
- عند الرجوع لتبويب المقدم أو التركيز عليه، تُرسل نبضة اتصال فورًا.

الصفحات:
- `index.html` البداية واتصال المقدم/الجرس.
- `game.html` شاشة اللعبة.
- `host.html` المقدم.
- `buzzer.html` الجرس.
