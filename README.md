# من أنا؟ — النسخة 12

هذه النسخة مبنية مباشرة على ملف "من انا 11" الذي رفعه المستخدم.

إصلاحات فقط — بدون تغيير التصميم أو طريقة اللعب:

1. نقل Heartbeat اتصال المقدم من:
   mn_ana/connections/host
   إلى:
   mn_ana_presence/host

   السبب: نبضة المقدم كانت تغيّر mn_ana كل 1.5 ثانية، فتجبر شاشة اللعبة والجرس والهوست على إعادة render.

2. شاشة اللعبة لا تعيد إنشاء خيارات السؤال إلا إذا تغير السؤال نفسه.
   تغيّر الجرس أو النقاط أو x2 لم يعد يعيد options.innerHTML.

3. الهوست لا يعيد إنشاء خيارات الإجابة إلا إذا تغير السؤال/الخيارات.

4. صفحة الجرس لا تمسح اسم المتسابق أثناء الكتابة.

5. تحسين تحديث حالة الجرس بحيث يظهر اسم أسرع لاعب إذا كان متوفرًا.

تم التحقق من:
- عدم وجود IDs مكررة.
- JavaScript Syntax في index / host / game / buzzer.
- بقاء QR وSession والجرس وx2 والنقاط والإجابة والنجوم وشاشة بداية الفقرة والإعدادات.
