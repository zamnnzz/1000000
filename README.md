# من أنا؟ — النسخة الكاملة

الصفحات:
- `index.html` شاشة اللعبة الرئيسية / العرض.
- `host.html` واجهة المقدم.
- `buzzer.html` واجهة الجرس للمتسابقين.
- `firebase-config.js` إعداد Firebase.

شاشة اللعبة الرئيسية متجاوبة مع:
- التلفزيون والشاشات الكبيرة
- اللابتوب
- التابلت
- الجوال
- الوضع الأفقي للشاشات القصيرة

## التشغيل
على Vercel:
- الصفحة الرئيسية: `/`
- المقدم: `/host.html`
- الجرس: `/buzzer.html`

## مهم
إذا كان `apiKey` داخل `firebase-config.js` ما زال يحتوي على `xxxxxxxx`، استبدله بالمفتاح الحقيقي من Firebase.
