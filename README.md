# من أنا؟ — النسخة 9

التغييرات:
- حذف اختيار الجولة من واجهة المقدم.
- ترتيب الفقرات أصبح تلقائيًا:
  1) بدون نقاط
  2) من أنا؟
  3) من القائل؟
- عند انتهاء أسئلة فقرة، تظهر شاشة انتقال كبيرة باسم الفقرة التالية.
- المقدم يرى زر "ابدأ الفقرة" فقط أثناء شاشة الانتقال.
- بعد بدء الفقرة، يكمل زر "السؤال التالي" بشكل طبيعي.
- إضافة أنميشن ظهور وتحرك للعناوين والبطاقات وشاشة الانتقال.
- لم يتم تغيير الجرس أو الباركود أو x2 أو النقاط أو طريقة إعطاء النقاط.
