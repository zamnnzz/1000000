# من أنا؟ — النسخة 13

مبنية على النسخة 12 فقط.

الإضافات:
- بعد انتهاء أسئلة الفقرة الأولى أو الثانية:
  - لا ينتقل السؤال مباشرة.
  - تظهر في واجهة المقدم شاشة انتقال باسم الفقرة التالية.
  - المقدم يضغط "ابدأ الفقرة التالية".
  - بعدها يبدأ أول سؤال في الفقرة الجديدة، وتبقى شاشة بداية الفقرة الحالية في شاشة اللعبة كما كانت.

- بعد انتهاء الفقرة الثالثة:
  - completedSections يصبح 3.
  - تظهر شاشة النتائج النهائية.
  - تعرض الفائز.
  - تعرض نقاط الفريقين.
  - تعرض فارق النقاط.
  - في حالة التعادل تعرض "تعادل".
  - تظهر مفرحات/Confetti وأنميشن بنفس ألوان تصميم الموقع.

- الجرس.
- الباركود والـSession.
- x2.
- نظام نقاط الأسئلة.
- إظهار الإجابة.
- اختيار الفريق وإعطاء النقاط.
- النجوم.
- شاشة بداية الفقرة لمدة 3 ثوانٍ.
- إصلاحات منع تكرار الخيارات.
