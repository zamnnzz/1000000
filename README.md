# من أنا؟ — النسخة 24

مبنية مباشرة على النسخة 22 (وليس 23).

تعديلات آمنة ومحدودة:
- رقم السؤال العلوي في الهوست مخفي بصريًا مع الحفاظ على مساحته حتى لا تتغير القياسات.
- رقم السؤال يبقى ظاهرًا في المنتصف بين السابق والتالي.
- التالي يظهر يسار، والسابق يمين، باستخدام CSS grid فقط بدون إعادة ترتيب HTML.
- أنميشن البداية تغيّر نصه فقط إلى "بدون نقاط" بدون تعديل JavaScript.
- عبارة "لعبة المسابقة التفاعلية" أصبحت غير ظاهرة مع الحفاظ على المساحة لتجنب تغيّر القياسات.
- أسماء الفرق أصبحت Placeholder فقط.
- تحقق إلزام كتابة الفريقين ومنع الاسم المكرر بقي كما هو في النسخة 22.

لم يتم تغيير أي منطق لعبة أو Session أو Firebase أو الجرس أو x2 أو النتائج.
