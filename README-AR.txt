نسخة Vite محسنة لموقع ألعاب زامن.

طريقة الرفع إلى Vercel:
1) ارفع المجلد كاملًا أو اربطه مع GitHub.
2) Framework Preset: Vite
3) Build Command: npm run build
4) Output Directory: dist
5) انشر أولًا كـ Preview وجرب الموقع قبل تحويله إلى Production.

هذه النسخة لا تحتاج Babel أو React أو Tailwind من CDN؛ يتم بناء الملفات مسبقًا.
